B03: Přehled rodinných výdajů

Vytvoř aplikaci v tomto čistém benchmarkovém projektu. Používej pouze syntetická data. Žádné reálné emaily, webhooky, platby ani externí účty. Dodrž specifikované rozhraní, protože výsledek ověří externí testy. UI musí být česky, přístupné klávesnicí, použitelné při 390x844 i 1440x900 bez horizontálního scrollu, s viditelnými chybami. Každý formulář musí mít programové labely a tlačítka s textem. Obsah vstupů vykresluj jako text, nikoli HTML. JSON API chyby vracej jako JSON se správným 4xx, nikdy neošetřenou 500. Data ulož trvale v projektovém prostoru, pokud scénář požaduje restart. API cesty i odkazy musí fungovat pod cestou uživatelského preview. Použij podporovaný Harness postup pro běžící službu nebo statické preview; na konci vrať skutečnou uživatelskou preview URL a stručný postup spuštění/restartu. Vzdálený localhost není doručené preview. Nepřepisuj externí přijímací testy. Testy modelu nejsou důkazem nezávislého přijetí. Maximální čas je uveden níže; po limitu bude běh ukončen. Nezakládej subagenty ani nové placené prostředky.

Časový limit hlavního běhu 600s; nejvýše jeden opravný běh 300s.

Vytvoř statický nebo serverový dashboard nad přiloženým expenses.csv. Import přes input[type=file] s label „CSV soubor“ a tlačítko „Načíst CSV“. CSV sloupce id,date,category,amount; UTF-8, čárky, standardní quoted CSV. Přesné peníze v haléřích: částky se dvěma desetinnými místy, záporné vratky povoleny, nečíselná částka, neexistující či prázdné datum, prázdné id jsou chybný řádek. Prázdná kategorie = „Nezařazeno“. Stejné id se shodnými hodnotami je duplicita a počítá se jednou; stejné id s jinými hodnotami je chyba, původní řádek zůstane. Výsledek: 6 platných, 1 duplicita, 4 chyby; totalCents=101480. Kategorie Potraviny=1129, Doprava=321, Bydlení=100000, Nezařazeno=30. Filtry kategorie (select label „Kategorie“, all je prázdná hodnota), datum od/do (label „Od“/„Do“, inclusive YYYY-MM-DD) a tlačítko „Filtrovat“. Každá změna se projeví v tabulce i grafu. Souhrnný stav JSON {totalCents,count,duplicateCount,errorCount,byCategory} vystav jako text v elementu data-testid="summary-json"; byCategory mapuje jména na integer cents. Po filtrování count,totalCents,byCategory odrážejí jen platné filtrované záznamy, errorCount a duplicateCount celý import. Tlačítko „Stáhnout zprávu“ musí stáhnout JSON stejného obsahu. Žádné NaN/Infinity. Prázdný filtr má count=0,totalCents=0,byCategory={}. Graf má data-testid="expense-chart" a přístupný název. Po reloadu zachovej import a filtry.

Nezávislé UI přijetí:
1. Načíst expenses.csv a nezávisle ověřit summary JSON, čitelnou tabulku i graf.
2. Potraviny -> 1129/2; vše 2026-11-05 až 2026-11-06 -> 30/2; rozsah 2027-01-01 až 2027-01-02 -> 0/0.
3. Stáhnout skutečný JSON a porovnat s právě zobrazenými filtry; reload zachová stav.
